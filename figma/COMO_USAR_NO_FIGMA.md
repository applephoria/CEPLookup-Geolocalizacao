# 🧱 Kit de Wireframes Low-Fi — Figma (100% Monocromático & Paridade com o Código)

Esta pasta contém os **wireframes estruturais de baixa fidelidade (Low-Fi Blockframes)** monocromáticos, desenhados para fácil inclusão no **README do GitHub** e importação direta no **Figma**.

---

## 📁 Arquivos (Projetados para Caber Perfeitamente no README)

1. **[`wireframe-card-fechado-dark.svg`](./wireframe-card-fechado-dark.svg)**: Card fechado (`350 x 440 px`) no tema escuro monocromático (`#0D1117` / `#161B22` / `#1C2128`).
2. **[`wireframe-card-aberto-dark.svg`](./wireframe-card-aberto-dark.svg)**: Card expandido (`800 x 440 px`) com painel do mapa à direita no tema escuro monocromático.
3. **[`wireframe-card-fechado-light.svg`](./wireframe-card-fechado-light.svg)**: Card fechado (`350 x 440 px`) no tema claro monocromático (`#F4F6F8` / `#FFFFFF` / `#F6F8FA`).
4. **[`wireframe-card-aberto-light.svg`](./wireframe-card-aberto-light.svg)**: Card expandido (`800 x 440 px`) com painel do mapa à direita no tema claro monocromático.

---

## 📐 Paridade com o Código Final

* **Dimensão Fechada:** `350 x 440 px`.
* **Dimensão Aberta:** `800 x 440 px` (`350px` painel esquerdo + `450px` painel do mapa).
* **Console do Radar:** `74px` de altura com telemetria e visor em bloco monocromático puro.
* **Espaçamento Uniforme:** Sem vão vertical excessivo, gap de `10px` entre radar e card de endereço.
* **4 Quick Chips de CEP:** 4 pílulas integradas de busca rápida.
* **Cores Monocromáticas:** Padrão clássico de UI Kit Low-Fi (cinzas, pretos e brancos técnicos), sem poluição visual.

---

## 🚀 Como Usar no Figma ou README

* **No Figma:** Basta arrastar qualquer um dos 4 arquivos `.svg` para o canvas do Figma.
* **Para embutir em um README.md:** Copie o código de exemplo abaixo (usando o botão de cópia `📋` no canto superior direito do bloco):
  ```markdown
  ### 📐 Wireframes Low-Fi

  ```
